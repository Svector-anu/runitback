# Next brief for Epoch: make the CapCut-class engine features usable, and make the editor work on small screens

State: transitions, adjust/filters, text stroke/shadow/animations, crop and freeze frame exist in the engine, frame plan, exporter and agent tools (docs/CAPCUT_PARITY.md lists the exact commands and UI wiring needed). The editor UI has no controls for them yet. The editor shell is desktop-only.

Orders, one PR each, smallest first. Every order: tests first (unit for logic, Playwright e2e for the flow, real pixel assertion where visual), follow CLAUDE.md invariants (preview and export share FramePlan+Compositor, commands go through Editor.execute, one undo step per gesture, no new heavy dependency), keep all existing specs green, honest empty/disabled states, tooltips/aria-labels, keyboard operable.

1. filters-and-adjust-panel: in the Properties panel for video/image clips, an 'Adjust' section: a FILTER_PRESETS picker (Vivid, Mono, Warm, Cool, Fade, Noir, Teal-Orange, Sepia, None) with thumbnails or labelled swatches and an intensity slider, plus sliders for brightness, contrast, saturation, exposure, temperature, tint, vignette, sharpen. Use addClipEffect/updateClipEffectParams exactly like the apply_filter tool (src/engine/agent/tools-props.ts). Gesture = preview then commit, one undo.
2. crop-and-text-style-panels: crop sliders (left/top/right/bottom, 0-0.95, keyframe diamonds like other params) for video/image; for text clips: stroke (width,color), shadow (enabled,color,blur,offset), and a text animation picker (in/out: none, fade, slide-up, pop, typewriter) calling setTextAnimationCommand.
3. transitions-at-cuts: a small handle/button rendered at each cut between touching clips on a track in the timeline; click opens a popover with the 7 types and a duration slider (clamped by maxTransitionDuration); shows an indicator on cuts that have a transition; remove option; calls setTransitionCommand; works with undo. Also wire the freeze-frame context-menu stub to freezeFrameCommand at the playhead.
4. mobile-editor-layout: below 900 px wide the editor shell must work: panels (Assets, Properties, Agent) become bottom sheets or tabs, the preview on top, a compact timeline below with horizontal scroll, touch-friendly 44px targets, pinch/scroll without breaking pointer gestures where possible; below 600 px show a dismissible notice 'RunItBack is built for desktop Chrome; mobile is limited' but keep it usable (import, play, add to timeline, split, agent chat with plan approval, export). No horizontal page scroll at 360/390/768; verify with Playwright at those sizes and screenshots into e2e/.artifacts/mobile/.
