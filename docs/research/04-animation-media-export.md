## 1. Time model (Rust `time` crate, exposed via opencut-wasm)

- `TICKS_PER_SECOND = 120_000` (i64) `R/time/src/media_time.rs:10`. `MediaTime(i64)` newtype `:16`. Exported to TS as `TICKS_PER_SECOND()` fn call `W/wasm/media-time.ts:27`.
- `FrameRate {numerator:u32, denominator:u32}` `R/time/src/frame_rate.rs:8`. Consts: 23.976=24000/1001, 24, 25, 29.97=30000/1001, 30, 48, 50, 59.94=60000/1001, 60, 120 (`:14-53`).
- `ticks_per_frame()` (`:82`) = `120000*den/num`, returns `None` unless it divides EXACTLY. Table (tests `:101-113`): 23.976->5005, 24->5000, 25->4800, 29.97->4004, 30->4000, 48->2500, 50->2400, 59.94->2002, 60->2000, 120->1000. `FrameRate::new(7,3)`, `(0,1)`, `(1,0)` -> None. So only rates that divide 120000 are legal; this is why 120_000 was chosen (LCM of common rates incl. NTSC via /1001 factor).
- `from_seconds_f64`: `round(seconds*120000)`, None if non-finite (`:30`). `to_frame_round`: euclid floor + round-half-up (`remainder*2 >= tpf`) (`:48`). `to_frame_floor`, `round_to_frame`, `floor_to_frame`, `is_frame_aligned`. `last_frame_time(duration)` = floor_to_frame(duration-1 tick) or 0 if <=0 (`:78`). `snapped_seek_time(time,duration,rate)` = round_to_frame then clamp [0,duration] (`:87`).
- Timecode (`R/time/src/timecode.rs`): formats `"MM:SS" | "HH:MM:SS" | "HH:MM:SS:CS" | "HH:MM:SS:FF"` (`:17-26`). Default format `HhMmSsCs` (centiseconds = 1200 ticks). `FF` needs rate: `frames = second_ticks / ticks_per_frame`. Parse validates minutes/seconds<60, cs<100, frames < ceil(num/den).
- `bridge` crate (`R/bridge/src/bridge.rs`): proc-macro `#[export]`; fns must take ONE options struct (compile error otherwise `:24-31`); snake_case->camelCase js_name; consts exported as getter fn returning f64 (`:43-61`). All wasm APIs therefore take `{...}` objects (matches TS `fn({a,b})` convention).
- Rust tests (all in-file): media_time `:363-427` (1.5s=180000 ticks; NaN/inf rejected; 1.26s@30fps -> frame 38 -> 152000 ticks; floor/round at +1 tick and +half frame; `last_frame_time` 10s@5fps = 9.8s, `snapped_seek_time(10s)` = 10s); frame_rate `:97-120`; timecode `:210-286` ("01:02:03:45" for 3723.45s; "00:00:01:15" for 1.5s@30; parse "01:05"=65s; "00:00:01:30"@30fps -> None; guess_format by part count 2/3/4); bridge `:85-94` (`do_something`->`doSomething`, `a_b_c`->`aBC`).
- TS wrapper `W/wasm/media-time.ts`: `type MediaTime = number & {__mediaTime}` branded integer (`:25`), ctor `mediaTime({ticks})` throws if non-integer (`:33-60`), `roundMediaTime` rounds half AWAY from zero and normalises -0 (`:69`), `mediaTimeFromSeconds` (wasm, throws on undefined) `:80`, `addMediaTime/subMediaTime/max/min/clamp`, `roundFrameTime`, `snapSeekMediaTime`, `lastFrameMediaTime`, `parseMediaTimecode`. `ZERO_MEDIA_TIME`.

## 2. FPS handling (`W/fps/`)

- Leaf vs composite is detected structurally: leaf if `Array.isArray(data.keys)`, composite otherwise (`channel-data.ts:13-23`). Leaf component key is always `"value"`. Colors are composite with keys `r,g,b,a` (linear-light RGBA, see §4). Legacy storage keys `"bindings"`/`"channels"` are filtered out (`channel-data.ts:7,55`).
- Scalar-vs-discrete channel detection: `"extrapolation" in channel || keys.some(k => "segmentToNext" in k)` (`interpolation.ts:174`). (Gotcha: an EMPTY scalar channel without extrapolation is classified discrete.)
- `getElementLocalTime` (`resolve.ts:13`): clamps `timelineTime - elementStart` into `[0, elementDuration]`. Callers also `Math.max(0, localTime)`.
- Keyframe times are CLIP-local, independent of retime (retime only maps source time).

### Evaluation (`interpolation.ts:241-349`, `bezier.ts`)
`getScalarChannelValueAtTime({channel,time,fallbackValue})`:
1. no channel/keys -> fallback. Channel is normalized (sorted by time, defaults `tangentMode="flat"`, `segmentToNext="linear"`, first key's leftHandle and last key's rightHandle dropped, handles clamped: right `dt` into `[0, span]`, left `dt` into `[-span, 0]`, span=max(1, nextTime-prevTime)) `:55-156`.
2. `time <= first.time`: if strictly before -> extrapolate with `extrapolation.before ?? "hold"`; at exactly first -> first.value. Symmetric for last (`:261-285`). Linear extrapolation uses the line through the edge key and its single neighbour (`:206-227`).
3. Find segment [left,right]; `time === right.time` returns right.value. `segmentToNext==="step"` -> left.value (hold). `"linear"` -> lerp with progress=(t-l)/span clamped 0..1. `"bezier"`: cubic Bezier in BOTH axes: P0=(l.time,l.value), P1=(l.time+rh.dt, l.value+rh.dv), P2=(r.time+lh.dt, r.value+lh.dv), P3=(r.time,r.value); missing handles default to 1/3 of span/delta (collinear => equals linear) (`bezier.ts:27-55`). Solve param u for x=time by BISECTION, `BEZIER_SOLVE_ITERATIONS = 20` (`bezier.ts:3,57-90`; assumes x monotone, guaranteed by handle clamping), then evaluate y(u) with `getBezierPoint` (standard Bernstein cubic).
Discrete (`:351-373`): last key with `key.time <= time`, else fallback (i.e. before the first key the static base value is used, unlike scalar which holds first key).
Color path (`resolve.ts:114-152`): fallback hex -> `parseColorToLinearRgba` (culori `parse`->`rgb`, sRGB->linear with the standard 0.04045 threshold / 2.4 exponent, alpha clamped 0..1), each r/g/b/a channel evaluated independently as scalar, recomposed with `formatLinearRgba` (linear->sRGB, clamp 0..1, `formatHex8` if alpha<1 else `formatHex`) (`params/index.ts:57-108`). Interpolating in LINEAR light, not sRGB.
Entry point: `resolveAnimationPathValueAtTime({animations, propertyPath, localTime, fallbackValue})` (overloads number/string/boolean/ParamValue). Helpers `values.ts`: `resolveOpacityAtTime`, `resolveNumberAtTime`, `resolveColorAtTime` (all `Math.max(0,localTime)`). `rendering/animation-values.ts:5` `resolveTransformAtTime` evaluates positionX/Y, scaleX/Y, rotate. `resolveGraphicParamsAtTime` (path `params.<key>`), `resolveEffectParamsAtTime` (path `effects.<effectId>.params.<key>`; `effect-param-channel.ts:9-10` prefix/suffix constants).

### Mutations (`keyframes.ts`)
- `upsertPathKeyframe({animations,propertyPath,time,value,interpolation?,keyframeId?,channelLayout,coerceValue})` (`:477`): coerce value (null -> no-op); pick target key id/time (match by keyframeId, else existing key at EXACT same time, else new UUID) using the primary (first) component channel (`:285-321`); decompose value per `ParamChannelLayout` (leaf: `{value}`; composite color: `decompose(hex)` to r,g,b,a); upsert per component: discrete comps via `upsertDiscreteChannelKey`, scalar via `upsertScalarChannelKey`. New scalar key: `segmentToNext` from interpolation arg ?? component default (`linear` for scalar, `hold` for discrete) mapped hold->"step"; `tangentMode:"flat"`. Updating an existing key keeps its handles/segment/tangent (`createScalarKey` copies previousKey) unless an explicit interpolation is passed. Result passes through `toAnimation` which drops empty channels and returns `undefined` if nothing left (`:70-85`).
- `removeElementKeyframe`, `retimeElementKeyframe` (move key time, re-sort; applies to every component channel that holds that keyframe id; composite colors share ids across r,g,b,a) `:1291,1324`; `updateScalarKeyframeCurve({propertyPath,componentKey,keyframeId,patch:{leftHandle?|null,rightHandle?|null,segmentToNext?,tangentMode?}})` (`:755`; `null` clears a handle).
- `splitAnimationsAtTime({animations,splitTime,shouldIncludeSplitBoundary=true})` (`:1231`): used for clip split and by `clampAnimationsToDuration` (split at duration, keep left; returns undefined if duration<=0 `:887`). Keys <= splitTime go left, >= splitTime go right with time re-based (`sub splitTime`). With boundary: inserts a key at the split point on both sides holding the evaluated value; for bezier segments it does exact de Casteljau subdivision (q0,q1,q2,r0,r1,splitPoint) to rebuild handles on both halves so the curve shape is preserved (`:1030-1100`, handles rounded with `roundMediaTime`); for linear/step simply inserts boundary keys. Discrete channels insert boundary key with evaluated value. Extrapolation preserved.
- `cloneAnimations({animations, shouldRegenerateKeyframeIds})` (`:836`): used for copy/paste and "separate audio" (`timeline/audio-separation/index.ts:129`).
- Commands: `UpsertKeyframeCommand` bounds time to `[0, element.duration]` before upsert and resolves per-path coerce/layout via `timeline/animation-targets.ts` (`commands/timeline/element/keyframes/upsert-keyframe.ts:73-90`). Others: remove, retime, update-scalar-keyframe-curve, upsert/remove effect-param keyframe; clipboard `paste-keyframes`, `clipboard/handlers/keyframes.ts`.

### Query (`keyframe-query.ts`)
`getElementKeyframes` flattens all channels into `ElementKeyframe[]` (one per unique time per path; for composite colors dedupes same-time entries preferring component index 0; value re-composed to hex at that time; `interpolation` = segmentToNext mapped step->"hold", discrete -> "hold") `:209`. `getKeyframeAtTime` exact tick equality `:256`. `hasKeyframesForPath`. `property-groups.ts`: `getGroupKeyframesAtTime` for `transform.scale` group (X+Y toggled together).

### Curve bridge / UI "easing" model (`curve-bridge.ts`)
Segment <-> CSS-style normalized cubic-bezier `[x1,y1,x2,y2]`: `x1 = clamp01(rh.dt/spanTime)`, `y1 = rh.dv/spanValue`, `x2 = clamp01(1 + lh.dt/spanTime)`, `y2 = 1 + lh.dv/spanValue`; inverse `rh.dt = round(span*x1)`, `rh.dv = spanValue*y1`, `lh.dt = round(span*(x2-1))`, `lh.dv = spanValue*(y2-1)`. `VALUE_EPSILON=1e-6`; if spanValue~0 uses `referenceSpanValue`, else null (flat segments non-editable). y may exceed [0,1] (overshoot).

3. image: `generateImageThumbnail` via `new Image()` + temp object URL (revoked after load) -> width/height = naturalWidth/Height.
4. video: `readVideoFile` (`media/mediabunny.ts:25`): `new Input({source:new BlobSource(file), formats: ALL_FORMATS})`; `duration = await input.computeDuration()`; `getPrimaryVideoTrack()` (throws "No video track found in the file"); `videoTrack.canDecode()`; `computePacketStats(100)` -> `averagePacketRate` = fps; `getPrimaryAudioTrack()` !== null -> `hasAudio`; if canDecode: `new VideoSampleSink(track).getSample(1)` (frame at t=1 second, NOT first frame; null if clip shorter than 1s or no sample -> thumbnail null: possible bug) drawn via `frame.draw(ctx,0,0,w,h)` then `frame.close()`; returns `{duration,width: displayWidth,height: displayHeight,fps,hasAudio,codec,canDecode,thumbnailUrl}`; `input.dispose()` in finally. Uses `displayWidth/Height` (rotation-aware). If !canDecode -> toast with codec-specific advice (hevc: "Convert to H.264 MP4 or try Safari"). Errors in probing -> toast, asset STILL added with missing metadata.
5. audio: duration via an `<audio>` element `loadedmetadata` (`getMediaDuration`, own temp object URL). No waveform/thumbnail at import.
6. progress: `Math.round(completed/total*100)`; `await setTimeout(0)` yield between files; per-file exception -> toast + `URL.revokeObjectURL(url)`.
- Thumbnail: `renderThumbnailDataUrl` (`media/thumbnail.ts`): fit within `THUMBNAIL_MAX_WIDTH=1280` x `THUMBNAIL_MAX_HEIGHT=720` preserving aspect (width clamp first then height), canvas `toDataURL("image/jpeg", 0.8)`. So `thumbnailUrl` is a `data:` URL string persisted inside metadata (not an object URL), though `clearAllAssets` still calls `URL.revokeObjectURL(thumbnailUrl)` (no-op for data URLs).
- Add to project: `AddMediaAssetCommand` (undoable; new UUID assetId pre-generated so timeline element can reference it in a `BatchCommand([addMediaCmd, InsertElementCommand])`; asset list updated optimistically, storage save async; on failure removes asset, deletes orphaned timeline elements, restores fps, quota toast) (`commands/media/add-media-asset.ts`). Element duration = `mediaTimeFromSeconds(asset.duration)` or `DEFAULT_NEW_ELEMENT_DURATION` for images/unknown; audio element created with dummy `new AudioBuffer({length:1,sampleRate:44100})` buffer in paste path (`use-paste-media.ts:88`).
- Persistence (`services/storage/service.ts`): file bytes in OPFS dir `media-files-${projectId}` keyed by asset id (`OPFSAdapter`, `getFileHandle(create)`, `createWritable`); metadata in IndexedDB DB `video-editor-media-${projectId}` store `media-metadata` (config names `projectsDb:"video-editor-projects"`, `mediaDb:"video-editor-media"`, `savedSoundsDb:"video-editor-saved-sounds"`, version 1) (`:60-102`). `saveMediaAsset` writes file then metadata; on error removes file and maps quota errors to `StorageQuotaExceededError` (matches name `QuotaExceededError`, `NS_ERROR_DOM_QUOTA_REACHED`, or message containing "quota"). **BUG/GAP: `saveMediaAsset` metadata (`:297-308`) omits `fps` and `hasAudio`, and `loadMediaAsset` (`:372-382`) doesn't return them, so after reload `fps`/`hasAudio` are undefined** (audio logic treats `hasAudio !== false` as audio-present, so audio-less videos reloaded are assumed to have audio; fps ratchet only works at import time). `loadMediaAsset` creates a fresh object URL per load; SVG with empty mime type is re-wrapped as `image/svg+xml` Blob (`:355-372`).
- URL lifecycle: URL created at import (processing.ts:120) or load; revoked in `RemoveMediaAssetCommand` (`remove-media-asset.ts:46`), `MediaManager.clearProjectMedia/clearAllAssets` (also clears `videoCache`/`waveformCache`). Removal is undoable (saved assets/tracks snapshots). Ephemeral flag exists on assets (`ephemeral?`), purpose not traced (OPEN).

### Preview frame decode (`services/video-cache/service.ts`)
Per-mediaId `Input(BlobSource)` + `CanvasSink(videoTrack,{poolSize:3, fit:"contain"})`; throws if `!canDecode`. `getFrameAt({mediaId,file,time})` serialises requests per media with a promise chain + seek-generation counter (stale requests return the current frame). Strategy: reuse `currentFrame` if `time ∈ [ts, ts+duration)`; promote prefetched `nextFrame` if ts<=time; if iterator exists and `lastTime <= time < lastTime+2.0` s step iterator forward (tolerance 0.05 s on next frame; abort if frame ts > target+1.0); else `sink.canvases(time)` new iterator (seek) and prefetch one frame ahead. Returns `WrappedCanvas {canvas,timestamp,duration}`. Same cache used by export (frame-accurate sequential access -> iterator path).

## 8. Waveforms

- `services/waveform-cache/service.ts`: `WaveformCache` map `sourceKey -> Promise<SourceWaveformSummary>` (dedup in-flight; evict on failure). Source priority: provided `AudioBuffer` -> `sourceFile.arrayBuffer()` -> `fetch(audioUrl)`; decode with a throwaway `AudioContext.decodeAudioData(buf.slice(0))` (note: uses WebAudio decoding, not mediabunny, for waveforms; so video files with unsupported container for decodeAudioData may fail) then `context.close()`. Source keys: `buildWaveformSourceKey({kind:"media"|"library", id})` => `"media:<id>"`/`"library:<id>"`.
- `media/waveform-summary.ts`: summary = per-bucket PEAK (max abs across channels) with `DEFAULT_SOURCE_WAVEFORM_BUCKET_SIZE = 128` samples; `SourceWaveformSummary {sourceKey,sampleRate,totalSamples,bucketSize,amplitudes: Float32Array}`. At draw time `buildWaveformSampleBuckets` maps pixel bars -> source sample ranges through trim + retime (`sourceStart + clipTime*rate`), `sampleSourceWaveformSummary` takes max over covered summary buckets. Also `computeRmsBuckets` with `RMS_ANALYSIS_WINDOW_SECONDS = 0.02` (max-over-20ms-windows RMS; comment in media/audio.ts:777-789 explains why). Timeline draw (`timeline/components/audio-waveform.tsx`): `BAR_WIDTH=1`, `BAR_GAP=1`, `WAVEFORM_GAIN_SAMPLE_COUNT=200` gain samples (`buildWaveformGainSamples` evaluates animated volume at `(i+0.5)/count*duration`), "burn" color `rgba(255,110,20,0.9)` for clipped part; height from `getBarFractionFromOutputAmplitude` (dB, floor -40).

## 9. Audio: decode, mix, playback, export-mix

Volume model: element `params.volume` in dB (default 0, clamp [-60,+20]); `params.muted` boolean; track `muted`; video element `isSourceAudioEnabled !== false` + `mediaAsset.hasAudio !== false` (`timeline/audio-separation/index.ts:57-73`). "Extract audio" creates an upload AudioElement copying trim/duration/retime/volume anim (new keyframe ids) and sets video `isSourceAudioEnabled=false`. **No fade-in/out, no per-clip pan, no EQ in this version.** "Fades" can only be emulated via volume keyframes. `resolveEffectiveAudioGain({element,trackMuted,localTime})` (`timeline/audio-state.ts:54`): 0 if muted else `dBToLinear(resolveNumberAtTime(volume path, localTime = round(localTimeSeconds*TICKS_PER_SECOND)))`. `buildAudioGainAutomation` samples gain every `DEFAULT_STEP_SECONDS = 1/60` s from..to (+ final point).

### Playback graph (`core/managers/audio-manager.ts`)
- One lazily created `AudioContext` (`createAudioContext`, webkit fallback). Master chain `createAudioMasteringChain`: `input GainNode (= playback volume)` -> `DynamicsCompressor` limiter -> `outputGain` -> destination. Limiter constants (`media/audio-mastering.ts:1-6`): threshold -1 dB, knee 0, ratio 20, attack 0.001 s, release 0.12 s, output headroom gain 0.98.
- Per clip: `AudioBufferSourceNode` -> `GainNode(clip volume)` -> master input.
- Clips collected by `collectAudioClips` (tracks order overlay..., main, audio; includes muted ones flagged `muted`; muted clips skipped at schedule time). Scheduler: `lookaheadSeconds=2`, `scheduleIntervalMs=500` (setInterval); clip scheduled when `clipEnd > now && clip.start <= now+2`; guarded by `activeClipIds`. Resume suspended context. Playback clock = `startTime + (ctx.currentTime - startContextTime)`.
- Two paths: (1) streaming: `AudioBufferSink.buffers(sourceStartTime)` async iterator (mediabunny), each decoded chunk becomes a source node started at `playbackStartContextTime + latencyComp + (timelineTime - playbackStartTime)`; retime via `node.playbackRate.value = rate` (pitch changes); late chunks start at `currentTime` with offset; after 5 consecutive dropped chunks, bumps latency compensation (max 0.25 s, +0.01 margin) and re-syncs; throttles when decoded > 1 s ahead (`waitUntilCaughtUp` polls 100 ms). Source start = `trimStart + clipTime*rate`. (2) prepared: used if animated volume OR pitch-preserve OR curve retime: whole source decoded via mediabunny + OfflineAudioContext resample to ctx rate (stereo cap), then `renderRetimedBuffer` for the clip span, cached by key {id,sourceKey,start,duration,trimStart,trimEnd,retime}; single node started with offset; volume automation = `gain.setValueAtTime` then `linearRampToValueAtTime` per 1/60 s point (skip past points).
- Seek/scrub: scrubbing stops playback; seek while playing restarts; any timeline/media change disposes sinks+caches and restarts if playing. `dispose` closes the context.

### Export mix (`media/audio.ts createTimelineAudioBuffer`)
`EXPORT_SAMPLE_RATE = 44100`, `MAX_AUDIO_CHANNELS = 2`. Steps: `collectAudioElements` (skips muted tracks, elements without audio/duration<=0) -> decode each source to an AudioBuffer: uploaded audio via `decodeAudioData`; video via mediabunny `Input.getPrimaryAudioTrack` + `AudioBufferSink.buffers(0)` concatenated (<=2 ch) then OfflineAudioContext resample from native to 44100; library (freesound preview) via `element.buffer` or `fetch(sourceUrl)` + decodeAudioData. Output buffer = stereo, `ceil(duration_s*44100)` samples. For each non-muted element: if pitch-preserve -> `renderRetimedBuffer`, then `mixAudioChannels`: per output sample `i` in `ceil(elementDuration*sr)`: `sourceTime = trimStart + clipTime*rate`, linear interpolation between neighbour source samples, `gain = hasAnimatedVolume ? resolveEffectiveAudioGain(localTime=clipTime) : element.volume(sampled once at localTime 0)`, ADD into output (channel mapping mono->both via `min(ch, srcChannels-1)`). Finally `applyAudioMasteringToBuffer`: if peak <= 0.98 return as-is, else offline render through the limiter chain and hard-clamp to +-0.98 (`audio-mastering.ts:55-103`). Cost note: whole mix is in memory.
- `extractTimelineAudio` (`media/mediabunny.ts:86`) builds a 16-bit PCM stereo WAV (44-byte header, 44100 Hz) with progress 10/90/100; empty timeline -> 0.1 s silence (`EMPTY_TIMELINE_SILENT_DURATION_SECONDS`), no audio -> silence of `max(0.001, duration)` (used for transcription path, not export; `decodeAudioToFloat32` mono mixdown helper at `media/audio.ts:62`).

## 11. Export pipeline (exact)

Options (`W/export/index.ts`): `EXPORT_FORMAT_VALUES = ["mp4","webm"]`, `EXPORT_QUALITY_VALUES = ["low","medium","high","very_high"]`, `ExportOptions {format, quality, fps?: FrameRate, includeAudio?: boolean}`, defaults `{format:"mp4", quality:"high", includeAudio:true}` (`export/defaults.ts`). MIME `video/mp4`, `video/webm` (`export/mime-types.ts`); extension `.${format}`. Resolution = project `settings.canvasSize` (no export-time resolution picker); fps = project fps (UI passes `activeProject.settings.fps`; `exportProject` falls back to it). UI (`components/editor/export-button.tsx`): popover with collapsible Format (MP4 H.264 "Better compatibility" / WebM VP9 "Smaller file size"), Quality (Low smallest / Medium balanced / High recommended / Very high largest), Audio checkbox; progress `Math.round(progress*100)%` + `<Progress>`, Cancel button; closing popover calls `cancelExport()+clearExportState()`; on success `downloadBuffer` (Blob + object URL + `<a download>` click, filename `${project.metadata.name}.${format}`) then closes; error panel with Copy/Retry.
Flow (`core/managers/renderer-manager.ts exportProject :141` via `ProjectManager.export :212`):
1. Guard: active project, `timeline.getTotalDuration() !== 0`.
2. If includeAudio: `onProgress(0.05)`; `createTimelineAudioBuffer({tracks, mediaAssets, duration})` (44.1 kHz stereo, see §9).
3. `buildScene({tracks, mediaAssets, duration, canvasSize, background})` -> `RootNode` tree (VideoNode/ImageNode/TextNode/StickerNode/GraphicNode/ColorNode/BlurBackgroundNode/EffectLayerNode).
4. `new SceneExporter({width,height,fps,format,quality,shouldIncludeAudio,audioBuffer})` (`services/renderer/scene-exporter.ts`).
5. Progress = `includeAudio ? 0.05 + p*0.95 : p`. Cancel: ProjectManager sets `exportCancelRequested`; `setInterval(checkCancel, 100)` polls `onCancel()` -> `exporter.cancel()` (sets flag only). Result `{success,buffer}|{success:false,cancelled:true}|{success:false,error}`.
SceneExporter.export (`:82-170`):
- `ticksPerFrame = round(120000*fps.den/fps.num)`; `frameCount = floor(rootNode.duration / ticksPerFrame)` (drops trailing partial frame).
- `Output({format: format==="webm" ? new WebMOutputFormat() : new Mp4OutputFormat(), target: new BufferTarget()})` (mediabunny, whole file in memory).
- Video: `new CanvasSource(renderer.getOutputCanvas(), {codec: webm ? "vp9" : "avc", bitrate: qualityMap[quality]})` where `qualityMap = {low: QUALITY_LOW, medium: QUALITY_MEDIUM, high: QUALITY_HIGH, very_high: QUALITY_VERY_HIGH}` (mediabunny relative-quality presets; bitrate resolved by mediabunny from resolution/codec, no explicit numbers in this repo); `output.addVideoTrack(videoSource, {frameRate: fps float})`. The source canvas is the WASM compositor's (WebGPU/GL) HTMLCanvas, not a 2D canvas.
- Audio (if includeAudio && buffer): codec `aac` for mp4 / `opus` for webm; for aac, if `AudioEncoder` exists and `AudioEncoder.isConfigSupported({codec:"mp4a.40.2", sampleRate, numberOfChannels, bitrate:192000})` is not supported -> fallback `opus` (note: opus-in-mp4). `new AudioBufferSource({codec, bitrate: qualityMap[quality]})`; `output.addAudioTrack`.
- `await output.start()`; then the ENTIRE audio buffer is added up front: `await audioSource.add(audioBuffer); audioSource.close()`.
- Loop `i in [0, frameCount)`: if cancelled -> `await output.cancel()`, emit `cancelled`, return null. `timeTicks = i*ticksPerFrame`; `await renderer.render({node: rootNode, time: timeTicks})` (resolve tree -> `buildFrameDescriptor` -> `wasmCompositor.syncTextures` -> `wasmCompositor.render(frame)`); `await videoSource.add(timeSeconds, 1/fpsFloat)` (timestamp seconds from `mediaTimeToSeconds`, duration one frame); emit progress `i/frameCount`. Sequential, no frame dropping, no worker.
- After loop: re-check cancel; `videoSource.close(); await output.finalize(); emit progress 1; buffer = output.target.buffer` (null -> error "Failed to export video"); emit complete.
- Not present: custom resolution/bitrate/codec choice, GOP/keyframe interval, audio-only export, pause/resume, streaming writes (StreamTarget), hardware-accel preference, progress ETA, mid-export audio muxing (audio is pre-rendered).
Snapshot: `saveSnapshot/copySnapshot` renders one frame at `min(playhead, lastFrameTime)` to PNG (filename `<project>-<timecode with : -> ->.png`).
